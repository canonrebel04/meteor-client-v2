## 2025-01-20 - Adding tooltips and placeholders to the Friends tab
**Learning:** Found that custom UI components (`WPlus`, `WMinus`, `WTextBox`) used in the `FriendsTab.java` did not have clear labels or tooltips. Icon-only buttons (`WPlus` and `WMinus`) are missing tooltips making it hard for users with screen readers or visual impairments to know their functions. Also, the text box for the friend's name lacks a placeholder, which could leave users confused about what text to input. By updating `theme.textBox("", ...)` to include `"Username"` and attaching `.tooltip` strings to the buttons, the UX is significantly improved.
**Action:** Always check icon-only buttons for missing `.tooltip` assignments and input fields for missing placeholders when working with this custom GUI framework.
